# Books By Kilo

A responsive, streaming-inspired storefront for browsing Books By Kilo's catalog.

## Features

- 155 locally stored Books By Kilo titles across nine real catalog collections
- Full-cover thumbnail treatment without cropping
- Ranked and category carousels
- Search, My List, cart feedback and book details
- Responsive desktop and mobile layouts

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
